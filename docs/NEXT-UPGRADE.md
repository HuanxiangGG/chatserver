## 已实现的第一模块：输入框

- 发送期间使用只读状态保留 textarea DOM 和焦点，不再禁用元素导致键盘/焦点移走；请求结束不抢回用户主动转移的焦点。
- 鼠标/触屏按发送按钮时，原本在 textarea 上的焦点不因按钮默认行为转移。键盘操作按钮仍保留正常无障碍行为。
- 成功清空当前草稿，失败保留内容；沿用发送锁和 clientId 幂等机制。同一发送未确认前保持只读，尚不支持同时编辑下一条消息或离线发送队列。
- 消息更新后只滚动消息容器，不滚动整个页面；查看历史时不追随新消息。历史分页保留原滚动偏移并阻止旧会话响应污染新会话。
- 设置支持 Enter 或 Ctrl/Command+Enter 发送，Shift+Enter 始终换行，中文输入法候选确认不发送；浏览器 localStorage 保存偏好。
- 保留加载图标尺寸，稳定消息滚动条宽度，限制输入区域横向尺寸。

根因：发送状态切换禁用了 textarea；异步请求完成时、React 提交重新启用之前调用 focus；scrollIntoView 还可能滚动页面祖先。改为保留同一个可聚焦的只读元素，并仅控制消息容器滚动。

修改文件：`frontend/src/chat.tsx`、`frontend/src/send-preference.ts`、`frontend/src/settings.tsx`、`frontend/src/styles.css`；DOM 测试位于 `backend/test/composer-dom.test.ts`；`backend/package.json` 与根锁文件新增 jsdom 开发测试依赖。
