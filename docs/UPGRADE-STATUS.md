## 本次独立模块

图片粘贴/拖拽/文件选择统一为 MediaDraft，选择时只本地预览，显式发送后经原认证上传 API 上传。普通文本粘贴不拦截。10MiB/5文件限制；服务端继续真实 MIME 检查。按会话保留内存草稿，离开聊天组件会释放，不声称跨刷新持久化。

失败时保留文字与文件，已确认上传的附件复用。消息 POST 的内容、回复、附件和 clientId 在首次尝试后固定，响应未知时禁用修改、允许原消息重试，避免以同一 clientId 发送不同内容。切换会话后旧请求不改写新会话内容。取消/成功/离开组件撤销 blob URL。

无 Schema、迁移、Docker、Caddy、权限和生产数据变更。保留现有群聊及好友入口，没有添加虚假的服务器/语音入口。
