# Harbor Chat 升级状态（2026-11-09）

本分支是分阶段升级开发版本，不代表线上完整升级或已经部署。main 仍是 dd7c909；线上截图显示的旧三栏界面不能证明此分支已发布。

## 已实现并验证的模块

### 社区与频道

新增 7 个模型：Server、ServerMember、ServerBan、ServerInvite、Channel、ChannelCategory、ChannelGrant。频道引用原 Conversation，消息、附件、回执和去重继续复用既有后端；没有复制消息表或修改旧迁移。

支持创建社区与 default general；文字频道新增/修改/分类/位置排序/私密授权/公告/归档；分类创建/重命名/删除保留频道；成员四级角色、禁言/解除禁言、移出/封禁/解除封禁 API；邀请预览/到期/限次/撤销，数据库仅存 Token 哈希，串行处理加入。

统一 channel-policy 在 HTTP 消息、Socket.IO 输入事件和附件读取校验，成员变化事务内更新既有 ConversationMember。分类引用必须属于同一社区，私密授权仅限现有成员；移除成员会清除原私密授权。管理操作使用 AdminAction 审计。

新增社区导航栏、频道分类、成员与设置、邀请预览页；保留好友/私聊/群聊和深浅主题，手机频道列表与聊天独立切换。数字设置位置排序，未提供拖动。社区角色显示于社区成员页。

### 媒体草稿

图片粘贴/拖拽/文件选择复用 MediaDraft，显式发送后上传，本地预览、移除、10MiB/5 文件限制。上传部分失败复用已成功附件，未知发送结果固定 clientId 和原消息信封；会话切换隔离草稿，取消/完成释放 blob URL。不声称跨刷新持久化。

## 迁移与生产限制

迁移仅新增社区表，未改变部署架构与卷。没有连接生产数据库、上传目录、Caddy 或容器；不能宣称生产数据已完成一致性验收。本次仍未取得生产日志，旧 502 的根因不能凭截图推断，最新用户截图仅能证明当时页面已打开。

社区生成数据后不能直接降级为不认识频道权限的旧后端。上线前还需确认服务器现有项目/挂载、备份并恢复到独立目标、核对数据、准备社区兼容回滚及 HTTPS/Socket 验收。当前不得把 Draft 当作生产成品直接部署。
