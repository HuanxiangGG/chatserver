# 完整升级实现与验收计划

此文记录实现约束和验收计划，具体实现与最新结果见 NEXT-UPGRADE.md 末尾及 README。历史测试数量不代表后续改动已经验证。

## 核查与模块边界

- 输入框：保留真实消息接口、发送锁和 clientId，验证失败草稿、焦点、历史滚动和 IME；需要补实际移动浏览器验证。
- 国际化：语言状态必须从声音设置模块剥离为共享模块，避免其他页面依赖声音状态；逐页迁移真实 UI/错误/Toast/通知，补完整键引用检查，禁止白名单绕过旧文本。
- 声音与通知：分离语言、偏好持久化、用户手势解锁、Socket 新消息判定和浏览器权限；补账户切换、重连、多标签页与实际浏览器回归，失败明确反馈。
- 搜索与预览：保留成员/频道权限与受保护下载接口；验证真实消息、字面关键词、分页、撤回/隐藏、定位与权限撤销。
- 转发：设计来源权限、目标写权限、附件权限继承和幂等事务后实现单条/批量及两种模式，不能直接复用附件 URL 绕过源会话权限。
- 群管理：原群与社区权限必须明确区分；统一禁言判断用于 HTTP、Socket、上传与群资料修改，公告、已读和审计贯通数据库与 UI。
- 举报/封禁：实现完整工作流、临时封禁到期、会话撤销和管理员审计；不允许只做后台按钮。
- 密码恢复：沿用一次性哈希令牌和会话撤销；SMTP 未配置时返回真实、统一的管理员恢复提示；不得记录生产重置链接。
- 备份：保留现有 Compose/Caddy/卷；自动化脚本之外还需真实 Docker 备份、独立库及目录恢复、数据与文件对比演练。

## 迁移约束

语言状态重构无需数据库迁移。已存在的两项新增迁移仅添加用户偏好表、搜索扩展和索引。公告/禁言、举报/临时封禁和转发元数据的后续表结构需在实现前说明并单独增量迁移；不得重写已应用迁移，不得清空或重置数据。

## 验收门槛

每次实现运行 i18n:check、typecheck、build、test；失败需继续修复。真实功能核对必须覆盖用户指定的注册登录、消息收发/连续发送、声音、搜索、预览、回复转发、公告禁言、系统通知、恢复、举报封禁、双语、移动端、重连、越权、迁移及备份。

提交前检查 git status、git diff --check 和 git diff --stat。所有未通过或因环境限制未验证的项目记录实际原因，禁止以静态页面、模拟测试或旧结果代替真实功能验收。全部门槛通过前不合并发布、不声明任务完成。

## 转发、群管理、举报与通知的接口设计

以下设计现已接入代码；三项增量迁移已在隔离测试库执行，生产未执行：

- ForwardBatch/转发来源：批量请求按调用者、clientId 幂等；来源消息必须仍可读、未隐藏/撤回，目标必须可写；附件不得复用指向私密源会话的下载地址，应复制受权存储对象并建立目标附件记录。批次失败不产生半条消息，回滚清理仅限本次新建副本。
- GroupAnnouncement/GroupAnnouncementRead：发布、修改、置顶、软删除及已读接口；每次验证群主/管理员角色并写 AdminAction。普通成员只有读取和标记已读权限。
- GroupMute：操作者、目标、原因、到期/永久状态；普通管理员只能禁言普通成员。共享写权限用于消息、编辑、Socket 输入提示、上传和群资料更新；过期按服务端时间判断，不能依赖前端计时器授权。上传必须绑定目标会话，禁言期间禁止为该会话产生附件。
- Report：用户、消息、附件、群组四类目标；创建时验证目标可访问，后台支持状态/原因过滤、处理和驳回。普通用户不能读取他人举报和后台 API。
- 临时封禁：User 增加到期和原因字段；封禁事务撤销会话，HTTP/Socket 共用认证逻辑。到期只允许重新登录，不恢复已撤销会话；自动到期与手动解封均记录审计。
- 浏览器通知：只从 Socket 新消息入口触发；独立于声音总开关，明确用户授权。过滤自己、当前活动会话、旧消息、重复消息和免打扰时段，点击按会话类型导航。拒绝授权或平台不支持时提供页面内反馈，不影响聊天。

相应成功、失败、加载、空状态、断线、越权及移动端验收必须随各模块一起完成。上述模块已经落地；实际验证与环境限制见 NEXT-UPGRADE.md 最终记录，不以本设计清单代替验收。
